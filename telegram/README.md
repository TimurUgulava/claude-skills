# Telegram — курьер с обязательным согласованием

Скилл для Claude Code: транспорт в Telegram от **личного аккаунта пользователя** поверх Telethon-сессии. Умеет три вещи — **отправить** сообщение в чат/личку, **найти** чат по названию, **прочитать** последние сообщения.

## Главное правило

**Ни одно сообщение не уходит без явного согласия пользователя в текущем диалоге.** Перед отправкой скилл делает «сухой прогон» и показывает карточку (чат + тип + id + полный текст 1:1), ждёт «да» и только потом отправляет. Это не настраивается и не отключается.

## Что делает

- **Отправка** (`tg_send.py`) — с обязательной карточкой согласования; реальная отправка только с флагом `--yes` после подтверждения.
- **Поиск чата** (`tg_resolve.py`) — read-only, по подстроке названия.
- **Чтение** (`tg_read.py`) — последние сообщения чата, read-only.

## Требования к окружению

| Что | Где | Примечание |
|---|---|---|
| `telethon` | `pip3 install telethon` | Python-библиотека |
| `api_id` / `api_hash` | macOS Keychain (`tg-api-id` / `tg-api-hash`) или env `TG_API_ID` / `TG_API_HASH` | взять на [my.telegram.org](https://my.telegram.org) → API development tools |
| Файл сессии | `~/.tg/tg_session.session` (или env `TG_SESSION`) | **главный секрет** — пройденная авторизация. В репозитории его нет |

> Секреты (api_id/api_hash и файл сессии) **не входят в репозиторий**. Настройте их у себя по `references/setup.md` перед первым запуском.

## Установка

```bash
cp -r telegram/ ~/.claude/skills/telegram/
```

## Как использовать

- «отправь этот текст в чат X» → скилл покажет карточку и спросит «Отправляю?»
- «найди чат “Команда маркетинга”»
- «прочитай последние сообщения в чате Y»

## Структура

```
telegram/
├── SKILL.md                 # ядро: протокол согласования, триггеры
├── references/
│   ├── safety.md            # правила безопасности отправки
│   └── setup.md             # окружение, ключи, восстановление доступа
└── scripts/
    ├── _tg_common.py        # общий модуль: ключи, сессия, клиент
    ├── tg_send.py           # отправка (с карточкой согласования)
    ├── tg_resolve.py        # поиск чата (read-only)
    └── tg_read.py           # чтение сообщений (read-only)
```
