## 2026-04-22 — Итерация 1: Кампания для онлайн-конференции, концепция «Коллега с ИИ»

**Источник:** Реальная сессия по созданию рекламных креативов для онлайн-конференции (Яндекс Директ ТГБ + VK Ads, 10+10 объявлений, кинематографический реализм). Все 9 правок — переработка авторских корректировок в системные правила скилла.

### Выявленные паттерны
1. Демография в таблице сегментов оказалась лишней — таргетинг идёт по интересам, не по «возраст/пол/доход»
2. Markdown-рендерер ломает `<br>` в ячейках таблиц — нужны карточки вместо длинных таблиц
3. Куцый формат BIG IDEA не давал автору достаточной аргументации — нужен развёрнутый разбор с обязательным блоком «где может не сработать»
4. Привязка концепции к одному «визуалу» вместо «дизайн-кода» (палитры приёмов) ломала Шаг 4 — на серию креативов нужно одно семейство приёмов, не один кадр
5. Включение `use_image_history=true` плюс конкретные декорации в стилевом блоке (open-space, MacBook, plants) дали 4 кадра одной фотосессии вместо серии — преемственность серии должна держаться на палитре/грейдинге, а не на сцене
6. Стандартное «5-10 объявлений» оказалось размытым — пользователь хочет ровно 10 по умолчанию для нормального A/B
7. Формула `=HYPERLINK()` в локали ru_RU отображается как plain text без подсветки клика — нужен rich text link через API
8. Таблица креативов без контекста бесполезна для подрядчика — нужна обязательная вкладка «Бриф» с фиксированной структурой

### Что НЕ внесено и почему
- **Личная преференция автора по склонению его фамилии не вшита.** Это user-правило конкретного автора (его auto-memory). Скилл универсальный — личные преференции в инструкцию не вшиваются. Проверено: дублей в скилле нет.

### Известные ограничения после итерации
- Шаблон стилевого блока в `visual-rules.md` дан только для одного стиля (кинореализм). Для других стилей (3D, flat, изометрия, акварель и т.д.) шаблоны добавятся в следующих итерациях по мере появления реальных кейсов.
- Структура «Брифа» зашита под Trial-кампании. Для других целей (Awareness, Lead-gen, Reactivation) набор секций может потребовать корректировки — пока работаем по фактам в следующих кампаниях.
