# Формат экспорта: Excel или Google Sheets

На Шаге 5 Кеша спрашивает у пользователя, **какой формат**:

> Куда сохраняем?
> 1. **Excel-файл (.xlsx)** — локально на диск, можно сразу открыть в Numbers/Excel
> 2. **Google Sheets** — в твой Google Drive, ссылку получишь, можно расшарить
> 3. И то, и то

## Структура столбцов (одинаковая в обоих форматах)

| Столбец | Содержимое |
|---------|-----------|
| № | Порядковый номер объявления |
| Концепция | Название выбранной Big Idea |
| Цель | Цель кампании (Performance / Awareness / etc) |
| Платформа_1_Заголовок | Основной заголовок для первой платформы |
| Платформа_1_Доп_заголовок | Дополнительный заголовок (если есть) |
| Платформа_1_Текст | Текст объявления для первой платформы |
| Платформа_2_Заголовок | Адаптированный заголовок для второй платформы |
| Платформа_2_Текст | Текст объявления для второй платформы |
| Промпт_для_визуала | Полный промпт для генерации изображения |
| Путь_к_изображению | Локальный путь файла из Nano Banana (или ссылка в Drive) |

Имена столбцов с «Платформа_1» / «Платформа_2» подменяются на конкретные названия — например, `ЯД_Заголовок`, `VK_Заголовок`.

## Правила
1. Данные — сухие, без персонажных реплик Кеши
2. ВСЕ столбцы заполнены — файл без пустых ячеек
3. Если для объявления не сгенерилась картинка — в столбце «Путь_к_изображению» поставить `—`, сообщить пользователю отдельно

## Вариант 1: Excel (.xlsx)

Файл сохраняется в текущую рабочую папку (или в `~/Documents/kesha-creatives/`, если рабочей нет).

**Имя файла:** `креативы_{slug-продукта}_{YYYY-MM-DD}.xlsx`

**Как генерить:** через Python-скрипт с `openpyxl` (стандартная библиотека), либо `pandas.to_excel()`. Скрипт пишется ad-hoc в Bash — отдельный xlsx-скилл не нужен.

## Вариант 2: Google Sheets

Используется скилл `google-workspace-pro`. Кеша делегирует через Skill tool:

```
Skill: google-workspace-pro
Args: создай таблицу "Креативы — {{продукт}} — {{дата}}", залей данные из {{источник}},
отформатируй: жирная шапка, зебра, автоширина столбцов, перенос текста, заморозка первой строки.
В таблице ДВЕ обязательные вкладки: «Бриф» (первой) + «Креативы» (второй).
```

### Обязательная вкладка «Бриф» (первой по порядку)

В Google Sheets экспорте Кеша **всегда** создаёт две вкладки. Первая — «Бриф», вторая — «Креативы». В Excel-экспорте «Бриф» опциональна (отдельный лист в xlsx).

**Структура «Брифа» — двухколоночная (лейбл / содержимое):**

| Колонка | Что |
|---------|-----|
| A | Лейбл (жирный, узкая колонка ~280px) |
| B | Содержимое (широкая ~700px, перенос текста) |

**Секции (заголовки на всю ширину строки, оранжевая заливка `#FF9900`, белый жирный текст 12pt, merge A:B):**

1. **Продукт** — название, формат, дата выступления, бонусы
2. **Цель кампании** — тип, KPI 1, KPI 2, что НЕ KPI
3. **Целевая аудитория** — сегмент, кто это, распределение бюджета между сегментами (если несколько)
4. **Главный страх (драйвер кликов)** — формулировка + почему работает (особенность психологии сегмента)
5. **Ключевые мотивации** — нумерованный список из 5-6 мотиваций с короткими подкреплениями
6. **Основные барьеры к регистрации** — 3-5 штук с объяснением, как нейтрализуем
7. **Креативная концепция** — название, главная идея (1 абзац), месседж, психологический инсайт, под цель
8. **Дизайн-код визуалов** — стиль, палитра, свет, грейдинг, типаж героя, эмоция, композиционный приём
9. **Площадки** — что куда (платформа → объявления N..M на вкладке «Креативы»), форматы визуалов
10. **Что важно проверить перед запуском** — модерация на грани, требования лендинга («бесплатно» → должен быть Free-тариф виден), мониторинг VK-комментариев

Бриф нужен подрядчику или коллеге, чтобы за 2 минуты восстановить логику кампании, не ходя в чат с Кешей. Без него таблица креативов = просто 10 текстов без контекста.

### Обязательная вкладка «Креативы» (второй по порядку)
Содержит ту самую таблицу из 10 столбцов (см. «Структура столбцов» выше). Лист переименовать с дефолтного «Лист1» на **«Креативы»**.

### Шаринг
После создания обеих вкладок — выставить `permission: anyone with link, role: reader` на:
- папку Drive (если картинки залиты в Drive)
- сам Google Sheet
- каждый файл картинки в Drive

Иначе HYPERLINK будут работать только у владельца. Делается через `drive.permissions().create()`.

После — показать пользователю:
> Готово:
> 📁 Папка: {{ссылка на папку}}
> 📊 Sheet: {{ссылка на Sheet}}
>
> Доступ — «любой по ссылке: смотреть» для папки, листа и всех картинок. Шарь подрядчику ссылкой, ничего отдельно не отправлять.

## Вариант 3: Оба

Делаются параллельно: сначала Excel (быстро, локально), затем Google Sheet. В чате — обе ссылки/пути.

## Изображения и экспорт

Картинки из Nano Banana лежат локально в `~/Documents/nanobanana_generated/`.

**В Excel:** в столбце «Путь_к_изображению» — абсолютный путь к файлу. Опционально — встроить превью в ячейку (через `openpyxl.drawing.image`), но это рискованно при большом количестве картинок (файл становится тяжёлым).

**В Google Sheets:** Кеша спрашивает у пользователя — заливать картинки в Drive или оставить локально?
- Если в Drive → загружает через `mcp__google-workspace__create_drive_file`, в столбце ставит публичную ссылку
- Если локально → в столбце путь, который доступен только на этой машине

**ВАЖНО: формат гиперссылок в столбце «Картинка».**
Использовать **rich text link** через Sheets API `batchUpdate` → `updateCells`:
```python
{
  "userEnteredValue": {"stringValue": "Открыть"},
  "userEnteredFormat": {
    "textFormat": {
      "underline": True,
      "foregroundColor": {"red": 0.07, "green": 0.34, "blue": 0.73},
      "link": {"uri": "https://drive.google.com/file/d/<ID>/view"}
    }
  }
}
```

**НЕ использовать формулу `=HYPERLINK("...";"Открыть")`** — в локали ru_RU она нестабильно отображается как кликабельная ссылка (иногда показывается как plain text без подсветки и без клика). Rich text link через API работает всегда.
