# Иннокентий (Кеша) — креативный директор

Скилл для Claude Code, генерирующий рекламные креативы для digital-платформ (Яндекс Директ, VK Ads и др.). Работает в образе живого креативного директора Кеши: спорит, аргументирует, не соглашается с первой попытки, но финальное слово оставляет за пользователем.

## Что делает

Полный конвейер от анализа аудитории до готового файла с креативами:

1. **Анализ ЦА** — сегменты, боли, мотивации, барьеры; накапливает портреты в библиотеке между сессиями.
2. **Концепция (BIG IDEA)** — развёрнутый разбор с обязательным блоком «где может не сработать» и дизайн-кодом серии.
3. **Тексты объявлений** — заголовки, тексты, CTA под форматы платформ с антимодерационной валидацией.
4. **Визуалы** — промпты + автогенерация через Nano Banana MCP.
5. **Экспорт** — в Excel или Google Sheets (вкладки «Бриф» + «Креативы»).

## Библиотека

Кеша накапливает портреты продуктов и аудиторий в `library/` и проверяет её первым делом на каждом запросе. **В этой публичной версии библиотека пуста** — она наполняется по мере ваших сессий. Формат и шаблоны — в `library/README.md`.

## Требования к окружению

| Компонент | Зачем |
|---|---|
| **Nano Banana MCP** (`nanobanana`) | автогенерация визуалов к объявлениям |
| **Google Workspace MCP** (`google-workspace`) | опционально — экспорт в Google Sheets |

## Установка

```bash
cp -r ad-creative-kesha/ ~/.claude/skills/ad-creative-kesha/
```

## Как использовать

- «Кеша, сделай креативы для VK под вебинар»
- «напиши 10 объявлений для Яндекс Директа»
- «нужны рекламные тексты под лендинг услуги»

## Структура

```
ad-creative-kesha/
├── SKILL.md          # ядро: шаги конвейера, персонаж, критические правила
├── references/       # анализ ЦА, копирайтинг, антимодерация, экспорт, платформы
├── library/          # накопительная база продуктов и аудиторий (пусто по умолчанию)
├── examples/         # пример сессии
└── CHANGELOG.md      # история калибровок
```

> Не используйте для SEO-текстов, статей блога, Telegram-постов, email-рассылок, лендингов и медиапланирования — у Кеши узкая специализация на рекламных креативах.
