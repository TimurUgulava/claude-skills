# Библиотека кадров-доноров

«Золотые кадры» упаковок брендов с **проверенно корректной кириллической этикеткой**, отрендеренной Nano Banana 2. Используются как `image_path` для серий с продакт-плейсментом — через приём package-preservation модель сохраняет упаковку с этого донора, а вокруг рисует нужную сцену.

## Как использовать донора в серии

```python
mcp__nanobanana__gemini_edit_image(
  conversation_id="<your-series-slug>",
  image_path="~/.claude/skills/risovalshchik/donors/<brand>.png",
  edit_prompt="""
    CRITICAL: keep the [Brand] package EXACTLY as it is in this input image —
    same label, same Cyrillic text, every letter intact. DO NOT redraw the package.
    
    Replace EVERYTHING ELSE in the scene with: <ваше описание новой сцены>.
  """,
  output_path="~/Downloads/images/<your-series>/0X-<step>.png"
)
```

## Когда добавлять нового донора

**Сразу после успешной генерации** упаковки для нового бренда: если в текущей серии Nano Banana случайно срендерила упаковку идеально (вся кириллица читается без ошибок), сохрани этот кадр сюда:

```bash
cp ~/Downloads/images/<series>/06-final-serve.png \
   ~/.claude/skills/risovalshchik/donors/<brand-product>.png
```

Имя файла: `<бренд>-<продукт>.png` в нижнем регистре через дефис, без пробелов и кириллицы. Примеры: `brand-sauce.png`, `coffee-arabica.png`.

## Структура донора

Хороший донор содержит:
- Упаковку **крупно и читаемо** (не в фоновом расфокусе) — чтобы edit от него мог отрисовать упаковку любого размера в новой сцене
- На **тёплом нейтральном фоне** (дерево, мрамор, льняная скатерть) — пригоден для большинства food-серий
- В **простом ракурсе** (top-down или фронтально-вертикально) — легче переносить в любую новую сцену
- **Без рядом стоящих сильных объектов**, которые могут «прицепиться» к упаковке при edit

Идеально, если донор сделан как изолированный «студийный» кадр упаковки (см. протокол создания донора в SKILL.md, раздел «Продакт-плейсмент»).

## Что есть сейчас

Библиотека доноров пуста — добавляйте «золотые кадры» по мере успешных генераций упаковок (см. раздел «Когда добавлять нового донора» выше).

## Контроль качества

Если после нескольких использований донора начали проявляться дефекты этикетки в новых сериях (Nano Banana может «дрейфовать» даже от стабильного донора при сложных промптах) — пересоздай донора по протоколу студийной генерации, замени файл, обновлять путь не нужно.
