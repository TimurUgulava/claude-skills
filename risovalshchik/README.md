# Рисовальщик (risovalshchik)

Универсальный генератор изображений для Claude Code. Рисует через **Nano Banana 2** (Google Gemini) или **GPT Image 2** (OpenAI) — при запуске спрашивает, какой моделью рисовать, и сохраняет результат в `~/Downloads/images`.

## Что делает

- **Одиночная картинка** — по текстовому запросу, с выбором модели.
- **Серия в одном стиле** — несколько кадров с единой палитрой/светом/посудой (рецепты, инструкции, пошаговые гайды) через приём преемственности.
- **Кириллица на картинке** — правила промптинга, чтобы модель рисовала русский текст буквами, а не латиницей.
- **Доноры упаковок** — библиотека «золотых кадров» брендовых упаковок для продакт-плейсмента (`donors/`), переиспользуемых через package-preservation.

## Требования к окружению

| Компонент | Зачем |
|---|---|
| **Nano Banana MCP** (`nanobanana`) | генерация и edit изображений (Google Gemini) |
| **GPT Image 2** (скрипт `scripts/generate_gpt_image.py`) | альтернативная модель; точный текст, 2K. Ключ читается из `.env` в корне скилла (`OPENAI_API_KEY`) |

> Файла `.env` в репозитории нет — создайте его сами и положите туда `OPENAI_API_KEY`, если используете GPT Image 2.

## Установка

```bash
cp -r risovalshchik/ ~/.claude/skills/risovalshchik/
```

## Как использовать

Скажите Claude Code:

- «нарисуй кота в скандинавском интерьере»
- «сделай серию из 5 кадров рецепта в одном стиле»
- «сгенери картинку для поста, кириллический заголовок на меловой доске»

Скилл сам спросит модель и приступит к генерации.

## Структура

```
risovalshchik/
├── SKILL.md                      # ядро: протокол, выбор модели, режим серии
├── references/prompting.md       # правила промптинга, кириллица, пресеты
├── scripts/generate_gpt_image.py # вызов GPT Image 2
└── donors/                       # «золотые кадры» упаковок (пусто по умолчанию)
```
