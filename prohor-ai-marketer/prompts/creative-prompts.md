# Промпт-шаблоны визуалов под недвижимость

Библиотека визуальных промптов этапа 4. Здесь — **что писать в промпт** (стиль-пресеты, структура, форматы, кириллический постер, серия). **Как и чем генерировать** (роутинг моделей, MCP/скрипт, edit-сессия, fallback) — `references/image-generation.md`. По умолчанию графика отдаётся чистой, без знака на самом изображении. Маркировка «это AI-картинка, а не фото объекта» живёт текстовым токеном `[▢ AI-визуализация]` в артефакте рядом с картинкой, а не в пикселях. Впечатать watermark в пиксель — опционально, только по явному запросу заказчика (механика — `references/image-generation.md`, раздел «Watermark „AI-визуализация“»). Полная команда GPT Image 2 под кириллический постер — `references/image-generation.md` (раздел «Вариант Б: GPT Image 2»).

Все шаблоны и примеры опираются на демо-объект — условный ЖК комфорт-класса (Приморский р-н СПб, намыв у Финского залива, стадия монолита, сдача 4 кв. 2027) — это вымышленный объект. Для реального заказчика подставляешь его паспорт из брифа.

## Три жёстких инварианта (повтор из `image-generation.md`)

1. **Промпт — всегда на английском.** Качество обеих моделей на русском промпте заметно ниже. Исключение — текст, который должен попасть НА картинку: он идёт в двойных кавычках + маркер `in Russian Cyrillic letters`.
2. **Каждое изображение — `[▢ AI-визуализация]`.** Каждый визуал помечается текстовым токеном `[▢ AI-визуализация]` в артефакте рядом с картинкой. Это не фото объекта — самый чувствительный риск рекламы недвижимости. По умолчанию графика отдаётся чистой, без знака на самом изображении: маркировка живёт текстовым токеном, а не в пикселях. Впечатать watermark в пиксель — опционально, только по явному запросу заказчика (механика — `references/image-generation.md`, раздел «Watermark „AI-визуализация“»).
3. **Никаких выдуманных фактов в кадре.** Этажность, материал, число корпусов, вид из окна — только из паспорта объекта. Чего нет в брифе — не рисуем «для красоты»: AI-рендер с несуществующим бассейном — это введение в заблуждение, ловит юрфильтр 214-ФЗ (`references/moderation-rules.md`).

> Голос Прохора: «Промпт пишу на английском не из снобизма — на русском обе модели мажут. А вот текст НА баннере — кириллицей и в кавычках, иначе модель нарисует транслит. Графику по умолчанию отдаю чистой, без знака в пикселе — что это AI-картинка, а не фото объекта, говорит текстовый токен `[▢ AI-визуализация]` рядом с макетом; впечатать watermark в пиксель могу опционально, по явному запросу заказчика. И да: я не дорисовываю объекту того, чего нет в брифе. Рендер с несуществующей набережной — это не креатив, это статья.»

## Структура сильного промпта

Единый каркас для любого пресета. Порядок секций держим — модель читает промпт сверху вниз и теряет середину на длинных.

```
[Style-preset вкладыш]            ← пресет стиля, всегда первым (якорь)
Subject: <объект + детальные прилагательные из паспорта>.
Composition: <как организованы элементы — ракурс, кадрирование, правило третей>.
Lighting: <свет и время суток — dusk / golden hour / overcast / interior warm>.
Style / medium: <архитектурный рендер / фотореализм / flat-инфографика>.
[Text block]                      ← только если на картинке нужен текст (см. постер)
Constraints: <негативы естественным языком; watermark-суффикс — опционально, только если заказчик явно просил знак в пикселе>.
```

**Длина промпта 80–200 слов.** Короче — мало контекста, длиннее — модель игнорирует середину.

**Камера (lens, aperture, depth of field) — только для фотореализма.** Для архитектурного рендера и инфографики упоминание камеры зашумляет и портит результат.

## Стиль-пресеты

Пресет = вкладыш в начало промпта. Один объект — один пресет на всю серию (стилевая преемственность, см. ниже). Выбор пресета — под класс объекта и креативный угол этапа 2, а не по вкусу.

### Пресет 1. Архитектурный рендер (clean architectural visualization)

Для котлована/монолита, где здания ещё нет — показываем проектный вид. Честнее всего читается как «визуализация проекта», не как фото.

```
Clean architectural visualization, photorealistic 3D render, accurate proportions,
realistic materials and glazing, neutral daytime sky, soft ambient occlusion,
no people in the foreground, professional real-estate rendering style.
```

Когда: ЖК на стадии котлован/монолит, БЦ, склад, генплан квартала, благоустройство до сдачи.

### Пресет 2. Премиум-лакшери (dusk-shot фасада)

Тёплый свет в окнах на синем часу — самый эмоциональный кадр для видовых и бизнес/премиум-класса.

```
Cinematic dusk architectural shot, blue-hour sky, warm glowing windows,
reflections on wet pavement and water, deep saturated tones, atmospheric haze,
premium real-estate photography mood, balanced exposure, subtle rim light on the facade.
```

Когда: премиум/бизнес-класс, видовые квартиры, набережная, hero-баннер кампании, обложка.

### Пресет 3. Lifestyle-фотореализм (резидент в среде)

Живой человек в интерьере/дворе — для семейных и молодёжных сегментов комфорт-класса. Это единственный пресет, где уместна камера.

```
Lifestyle photorealism, natural candid moment, soft window light, warm true-to-life
skin tones, shallow depth of field, 35mm lens, editorial real-estate lifestyle photography,
authentic everyday scene, no posing.
```

Когда: семейный сегмент (двор без машин, евро-планировка), молодая пара, интерьер white-box/чистовой, лобби, входная группа.

> Лица и руки — слабое место генераторов. Лицо держи в среднем/общем плане или со спины/в профиль; руки занимай действием («holding a coffee cup», «hands in stroller»), не оставляй растопыренными в кадре.

### Пресет 4. Минимализм / инфографика

Для УТП, квартирографии, схемы локации, absorption-блока — структурный визуал без фото.

```
Clean flat vector infographic, minimalist real-estate style, generous whitespace,
muted palette with a single accent color, simple geometric icons, thin consistent
line weight, no photographic elements, no gradients-to-purple.
```

Когда: схема «12 минут до метро», квартирография (студии/евро-2/евро-3), УТП-сетка, тайминг очередей, stat-блок с числами из паспорта.

> Числа на инфографике — только из паспорта/библиотеки с источником. Доля студий «~35%» — это `[△ требует подтверждения]` из брифа, на картинке подаём как факт объекта, не как рыночный бенчмарк. Доходность, прирост цены, «инвестиционная привлекательность» на инфографике — **запрещены** юрфильтром, не рисуем даже схемой.

## Формат-мэппинг под площадки

Базовый пакет этапа 4: **1:1, 4:5, 9:16, 16:9**. Технику смены формата (`set_aspect_ratio` / `--size`) — в `references/image-generation.md`. Здесь — какой формат под какой канал и что в кадре меняется.

| Формат | Канал | Что в кадре |
|--------|-------|-------------|
| 1:1 | Лента VK, РСЯ, карточка классифайда (Авито/Циан), превью | Центрированный фасад или один объект, текст минимальный/в плашке |
| 4:5 | Мобильная лента VK / соцсети (занимает больше экрана) | Вертикальная композиция, фасад снизу-вверх, воздух сверху под подпись вёрстки |
| 9:16 | Stories, Reels, вертикальный экран | Полноэкранная вертикаль, фокус крупно, место под стикеры/CTA сверху и снизу |
| 16:9 | DOOH, медийка РСЯ, десктоп-баннер, YouTube | Ландшафт, фасад + среда (залив, набережная), горизонтальный простор |
| 6:1 (опция) | DOOH-суперсайт, цифровой билборд | Сверхширокий — фасад тянется по горизонтали, текст крупно справа/слева |

Композиция под формат — не просто кроп: под 9:16 фасад снимаем снизу-вверх (вертикаль здания работает), под 16:9 даём горизонт залива и набережную. Поэтому серию строим от **одного эталона** и пере-кадрируем (edit от `history:0`), а не генерим с нуля каждый формат — иначе здание дрейфует (`references/image-generation.md`).

## Кириллический постер с заголовком и ценой

Постер-наружка с русским заголовком и ценой числами — задача **GPT Image 2** (чище кладёт кириллицу; Nano Banana системно плывёт на длинных русских словах). Полный шаблон команды — `references/image-generation.md` (раздел «Вариант Б: GPT Image 2», подраздел «Постер-наружка с кириллицей»). Здесь — каркас текстового блока промпта.

Правила текста на картинке:
- **Точный текст в двойных кавычках** + `in Russian Cyrillic letters` после каждого блока. Без маркера — модель нарисует латиницу/транслит даже при русском замысле.
- **Шрифт → вес → цвет → позиция** для каждого блока текста.
- **Цена — числами** (разрешено), формулировка «от 215 000 ₽/м²». Источник цены — прайс застройщика, статус `[△ требует подтверждения]`; в кадр идёт как факт объекта.
- **Запрещено юрфильтром** (214-ФЗ / ФЗ-38, `references/moderation-rules.md`): доходность %, «прирост цены», «инвестиции выгодно», ставка ипотеки без банка, «лучший/единственный», обещания. Цена и «Старт продаж» — можно.
- **Длинная кириллица — риск.** Длинный заголовок проговариваешь: «режу на короткие слова или выношу под рендер в плашку вёрстки». Не итерируй по 5 раз.

Каркас текстового блока (вставляется в общий промпт перед Constraints):

```
The headline reads "КВАРТАЛ У ЗАЛИВА" in Russian Cyrillic letters,
bold condensed sans-serif, white, upper part of the frame.
A status line reads "СТАРТ ПРОДАЖ" in Russian Cyrillic letters, smaller, white.
A price plate at the bottom reads "от 215 000 ₽/м²" in Russian Cyrillic and digits,
clean sans-serif on a solid plate.
```

Пример полного постера (фасад dusk + текст) для GPT Image 2:

```
Photorealistic outdoor billboard mockup of a comfort-class residential complex
by the waterfront at dusk, warm glowing windows, blue-hour sky, calm sea horizon.
The headline reads "КВАРТАЛ У ЗАЛИВА" in Russian Cyrillic letters, bold condensed
sans-serif, white, top of the frame. A status line reads "СТАРТ ПРОДАЖ" in Russian
Cyrillic letters below the headline. A price plate at the bottom reads "от 215 000 ₽/м²".
Clean composition, no extra text, no people.
```

> Голос Прохора: «„Старт продаж“ и цену числами — кладу. Доходность 14% и „лучший ЖК района“ — не кладу, это штраф ФАС, а не креатив. Длинный заголовок на наружке режу на короткие слова: чем длиннее русское слово, тем выше шанс, что модель уронит букву.»

## Стилевая преемственность серии

Один объект = один пресет, одна оптика, один свет на всю серию. Меняем **сюжет и локацию** (фасад → двор → интерьер → схема локации), держим **палитру, оптику, время суток, тип материалов**. Так пакет креативов читается как одна кампания, а не как нарезка из стоков.

Механика преемственности:
1. **Эталон первым.** Генерируем hero-кадр (обычно dusk-фасад 16:9) — он задаёт палитру и свет серии.
2. **Якорный блок для остальных кадров** — конкретный, не «in the same style». Перечисляй буквально:

```
Maintain the EXACT same dusk lighting, same blue-hour palette, same warm window glow,
same material rendering and color grade as the reference series.
Change only the subject to <новый сюжет — courtyard without cars / interior white-box / location map>.
```

3. **Кадрирование форматов — edit от эталона** (`history:0`), не от предыдущего кадра (`references/image-generation.md`).
4. **Токен `[▢ AI-визуализация]` — у каждого кадра серии** без исключений (текстовый токен в артефакте, не знак в пикселе). Впечатывание watermark в пиксель — опционально, только по явному запросу заказчика и тогда единообразно по всей серии.

Что держим неизменным по серии: палитра, время суток (dusk остаётся dusk), тип света (тёплый в окнах), grade/тон, оптика. Что меняем: субъект (фасад / двор / лобби / схема), формат, план.

> Голос Прохора: «Серия — это не пять разных картинок, это одно настроение в пяти кадрах. Поймал dusk на фасаде — двор и лобби тоже dusk, тот же тёплый свет, та же палитра. Иначе в ленте это смотрится как купленные стоки, а не как наш демо-объект.»

## Watermark-суффикс (опция, по явному запросу)

По умолчанию графика отдаётся чистой, без знака на самом изображении. Маркировка «это AI-картинка, а не фото объекта» живёт текстовым токеном `[▢ AI-визуализация]` в артефакте рядом с картинкой, а не в пикселях. Впечатать watermark в пиксель — опционально, только по явному запросу заказчика.

Полная логика — `references/image-generation.md` (раздел «Watermark „AI-визуализация“»). Если заказчик попросил знак в пикселе, в секцию Constraints промпта добавляется краткий суффикс (обе модели):

```
A small, delicate, semi-transparent watermark reading "AI-визуализация"
in Russian Cyrillic letters, placed in the lower-right corner, low opacity,
not covering the main subject.
```

- Когда заказчик включил опцию — watermark **в пикселе** не теряется при пересылке макета; иначе по умолчанию его в кадре нет.
- При включённой опции — дублируется суффиксом `-ai-viz` в имени файла и строкой в `campaign_matrix`. По умолчанию (чистая графика) — этого дубля нет.
- Включается **только по явному запросу заказчика под его ответственность** — решение фиксируем в `campaign_matrix`.

## Типовые ошибки промпта (чек перед генерацией)

| Ошибка | Симптом | Фикс |
|--------|---------|------|
| Забыл `in Russian Cyrillic letters` | На постере латиница/транслит | Маркер языка после каждого текстового блока в кавычках |
| Keyword-спам (`8k, masterpiece, best quality`) | Серый невыразительный кадр | Описывай словами, без артефактов SD-эпохи |
| Камера в промпте инфографики | Диаграмма «полу-фото», артефакты | Камеру — только в lifestyle-фотореализме |
| Несколько одинаковых объектов («корпуса») без счёта | Модель теряет счёт | «three buildings: 9, 12 and 18 storeys» вместо «several buildings» |
| Растопыренные руки в кадре | Лишние пальцы | Заняты действием или вне кадра |
| «in the same style» вместо якорного блока | Фасад дрейфует по серии | Перечисляй конкретно: палитра, свет, материал, grade |
| Дорисовал объекту фичу, которой нет в брифе | Юридический риск, рендер врёт | Только факты паспорта; нет в брифе — нет в кадре |
| Забыл токен `[▢ AI-визуализация]` в артефакте | Визуал без маркировки «это AI-картинка, не фото» | Токен `[▢ AI-визуализация]` рядом с каждым визуалом (по умолчанию маркировка текстовая, не в пикселе) |
| Впечатал watermark в пиксель без запроса заказчика | На самом изображении знак, которого заказчик не просил | По умолчанию графика чистая; watermark-суффикс в Constraints — только по явному запросу |
