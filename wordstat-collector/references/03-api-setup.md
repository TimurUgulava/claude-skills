# API setup

## Один ключ

Скилл использует один env var:

```
PIXELTOOLS_API_KEY=ваш_ключ
```

Этот ключ покрывает методы основного Pixel Tools (`tools.pixelplus.ru/api`): Wordstat, расширение ядра, кластеризацию.

## Получение ключа

1. Регистрация: https://tools.pixelplus.ru/
2. Активировать тариф с доступом к API.
3. ЛК → Настройки → API → сгенерировать ключ.
4. Скопировать `.env.example` → `.env` и вписать ключ:

```bash
cp wordstat-collector/.env.example wordstat-collector/.env
# затем впиши ключ в строку PIXELTOOLS_API_KEY=
```

## Где живёт `.env`

```
wordstat-collector/.env
```

Скрипты читают его автоматически (`python-dotenv`, путь — относительно папки скилла). Если ключа нет — сбор не идёт: без Wordstat ядро будет фантомным.

**Не путать**: `.env` рядом со скриптами скилла, а не в рабочей папке проекта. `.env.example` — шаблон без ключа; реальный ключ кладётся в `.env` (он в `.gitignore`).

## Проверка ключа

```bash
python scripts/smoke_test.py
```

Под капотом — запрос к `getlimits`:

```bash
curl -s "https://tools.pixelplus.ru/api/getlimits?key=$PIXELTOOLS_API_KEY"
```

Важно: параметр называется `key`, не `api_key`. Должен вернуть JSON с лимитами. Если приходит ошибка авторизации — ключ неправильный или просрочен.

## Лимиты одного цикла

| Шаг | Метод | Запросов | ~Лимиты |
|---|---|---|---|
| Частотность seed'ов | `wordstatapi` | ~7 | ~7 |
| Расширение | `wordstatapikeywords` | ~5 seed × страницы | ~200 |
| Обогащение расширения | (входит в расширение) | 0 | 0 |
| Кластеризация (опц.) | `gruppirovka` | 1 | ~100 |
| **Итого** | | | **~300 лимитов** |

Точная стоимость зависит от числа seed'ов, глубины парсинга (`--count-pages`) и размера ядра.

## Если ключ не работает

1. **Баланс лимитов**: `curl https://tools.pixelplus.ru/api/getlimits?key=...` — возможно, израсходованы.
2. **IP-ограничения**: некоторые тарифы ограничивают IP. ЛК → API.
3. **Подписка**: проверь, не просрочен ли тариф.
