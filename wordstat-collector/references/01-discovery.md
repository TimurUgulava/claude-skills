# Что собираем (Этап 0)

Для сбора ядра нужно минимум два параметра: **маркер** и **регион**. Не спрашивай лишнего — без чего следующие шаги не идут, того и не нужно.

## Маркер-запрос

**Вопрос:** Дай одну фразу, по которой к тебе должны приходить клиенты. Это главный поисковый запрос, от него развернём всю семантику.

Примеры: «ремонт пластиковых окон», «доставка цветов», «онлайн-курсы английского для взрослых».

- **Несколько фраз** — попроси выбрать одну главную. По остальным можно запустить отдельный цикл.
- **Длинная фраза** («ремонт окон с выездом мастера в день обращения недорого Москва») — упрости до базовой формы: «ремонт пластиковых окон».

## Регион (lr-код)

**Вопрос:** В каком регионе работаешь? Частотность забирается именно по этому региону — спрос в Москве и в небольшом городе сильно разный.

Стандартные коды Яндекса:

| Регион | lr |
|---|---|
| Москва | 213 |
| Санкт-Петербург | 2 |
| Екатеринбург | 54 |
| Новосибирск | 65 |
| Краснодар | 35 |
| Самара | 51 |
| Казань | 43 |
| Нижний Новгород | 47 |
| Ростов-на-Дону | 39 |
| Челябинск | 56 |
| Уфа | 172 |
| **Вся Россия (без регионального фильтра)** | **225** |

Если региона нет в таблице — найди код в справочнике lr-регионов Яндекса.

## Шаблон `input-brief.md`

После уточнения сохрани минимальный бриф в `.wordstat-session-YYYY-MM-DD/input-brief.md`. Скрипты вытаскивают из него регион автоматически (ищут «Код lr» или `lr=`):

```markdown
# Бриф

**Маркер**: ремонт пластиковых окон
**Регион (Код lr)**: 213 (Москва)

## Контекст (опционально)
Мастерская по ремонту окон с выездом. Чужой интент — «своими руками», «отзывы» — не нужен.
```

Поле «Контекст» необязательное, но помогает Claude точнее классифицировать ключи и отсекать чужой интент на контрольной точке.
