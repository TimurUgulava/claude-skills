# Fact-Checker Pro

Claude Code скилл: промышленный фактчекер внешних материалов. Берёт статью (вставленный текст, URL или файл) и превращает её в таблицу проверки — каждое утверждение со статусом «Истинно» / «Ложно» / «Неясно», реальными источниками и итоговым вердиктом о надёжности материала.

> Ключевой принцип: **ни одного статуса без реально открытой ссылки.** Выдуманный URL обесценивает весь отчёт — поэтому каждый источник проходит через WebFetch, а не берётся «по памяти».

---

## Что делает

Конвейер из 7 шагов:

1. **Приём входа** — вставленный текст, URL (загрузка через WebFetch) или файл (docx / pdf / md).
2. **Чеклист-план** — в начало ответа выводится план проверки.
3. **Декомпозиция** — текст разбивается на атомарные утверждения в порядке появления, каждому присваивается тип и приоритет.
4. **Верификация** — по каждому факту WebSearch находит ≥3 независимых источника, WebFetch **открывает каждый URL** и подтверждает, что он реально содержит факт; ставится статус и уровень уверенности.
5. **Таблица** — сборка результата по шаблону.
6. **Вердикт-саммари** — счётчики Истинно/Ложно/Неясно, красные флаги, вывод о надёжности.
7. **Финальная сверка и выгрузка** — проверка покрытия, сохранение `.md`, по запросу — Google Sheets или Excel.

---

## Фишки

- **Антигаллюцинация ссылок.** Каждый URL реально открывается через WebFetch. Не открылось — честное «Неясно» + N/A, а не правдоподобный фейковый адрес.
- **Классификация утверждений.** Факт / оценка / мнение / прогноз. Фактчекается только проверяемое; субъективные фразы не получают ложного «Ложно».
- **Тир источников (T1–T4).** Три блога ≠ три независимых авторитетных источника. Оценивается авторитетность и независимость, а не только количество.
- **Приоритет + уверенность.** Метка критичности (ключевой факт vs проходной) и уровень уверенности проверки — видно, где рвать в первую очередь.
- **Итоговый вердикт.** Сводка над таблицей с красными флагами (ложные критичные факты).
- **Промежуточная валидация.** После декомпозиции и после верификации — короткая самопроверка, чтобы ни одно утверждение не выпало.

## Требования к окружению

| Компонент | Статус | Зачем |
|---|---|---|
| **WebSearch / WebFetch** | встроенные | поиск и реальная верификация источников (ядро работы) |
| **Google Workspace MCP** | опционально | экспорт таблицы в Google Sheets |
| `openpyxl` (`pip install openpyxl`) | опционально | экспорт в Excel `.xlsx` |

> Без веб-инструментов скилл не выполняет свою главную функцию — реальную проверку источников. Экспорт в Sheets/Excel нужен только по явному запросу; базовый вывод (таблица в чат + `.md`) работает всегда.

## Установка

```bash
git clone https://github.com/TimurUgulava/claude-skills.git
cp -r claude-skills/fact-checker-pro ~/.claude/skills/fact-checker-pro
```

(для проектного скилла — в `.claude/skills/fact-checker-pro/` внутри репозитория проекта).

После установки скилл активируется по триггерам — отдельного включения не требуется.

## Как использовать

Скилл включается на фразы и контекст проверки фактов:

- «проверь факты», «фактчек», «фактчекинг», «проверь достоверность»;
- «проверь статью на факты», «верификация фактов», «насколько это правда»;
- когда вы даёте статью / текст / URL / файл и просите проверить факты.

Примеры:

- «Проверь факты в этой статье» + вставленный текст
- «Фактчек вот этой публикации» + URL
- «Насколько достоверны цифры в этом отчёте?» + файл
