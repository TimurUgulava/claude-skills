# Формат вывода: таблица, вердикт, экспорт

## Порядок вывода в ответе

1. **Чеклист-план** (Шаг 2) — пронумерованный plain-text список в самом начале.
2. **Вердикт-саммари** (Шаг 6) — сводка над таблицей.
3. **Таблица проверки** — основной артефакт.
4. **Финальное подтверждение** покрытия (Шаг 7).

Саммари ставится над таблицей, чтобы автор сразу видел вывод; детали — ниже.

---

## Структура таблицы

Полная структура (для .md, Google Sheets, Excel):

| Колонка | Содержимое |
|---------|-----------|
| **№** | Порядковый номер утверждения |
| **Утверждение** | Оригинальный текст (дословно или минимально сжато без потери смысла) |
| **Тип** | факт / оценка / мнение / прогноз |
| **Крит.** | критичный / второстеп. |
| **Статус** | Истинно / Ложно / Неясно / — |
| **Увер.** | высокая / средняя / низкая (для типа «факт») |
| **Источник 1** | Полный кликабельный URL страницы-пруфа + тир: `[https://…/точная-страница](https://…/точная-страница) [T1]` |
| **Источник 2** | Полный кликабельный URL / N/A |
| **Источник 3** | Полный кликабельный URL / N/A |
| **Комментарий** | Объяснение результата, пометки о дроблении/слиянии, противоречиях, недоступности |

Правила заполнения:
- Порядок строк = порядок утверждений в статье.
- Для типа не-«факт» статус всегда «—», источники «N/A», в комментарии — почему не
  фактчекается.
- **Источник — всегда полный кликабельный URL той страницы, где реально лежит пруф**, а не
  просто домен. Пиши `[https://monreposmuseum.ru/obekty-parka/kraj-sveta/](https://monreposmuseum.ru/obekty-parka/kraj-sveta/) [T1]`,
  а не «monreposmuseum.ru [T1]»: автор должен прокликать ячейку и попасть точно на
  подтверждение. Формат — markdown-ссылка `[URL](URL) [Tn]`, чтобы клик работал в любом
  рендерере. Библиографическое описание — только когда стабильной ссылки нет (печатный
  источник, платный архив). При <3 источниках свободные поля — «N/A» + пометка в комментарии.
- В комментарии к спорным фактам приводи точку опоры (что именно источник утверждает).

**Компактный вид для чата:** если 10 колонок не помещаются, допустимо свернуть три колонки
источников в одну «Источники» со списком кликабельных ссылок (`1. [URL](URL) [T1] · 2. …`) —
полнота и кликабельность URL сохраняются и здесь, сворачивается только раскладка по колонкам.
В экспортном файле держи полную структуру. Шаблон и образцы → `assets/table-template.md`.

## Вердикт-саммари

Шаблон блока над таблицей:

```
## Вердикт

- Проверено утверждений: N (фактов: X, оценок/мнений/прогнозов: Y)
- Истинно: A · Ложно: B · Неясно: C
- 🔴 Критичные ошибки: [перечисли ложные критичные факты или «нет»]
- Общий вывод: [1–3 предложения о фактической надёжности материала]
```

Красные флаги — это ложные утверждения с приоритетом «критичный»: они выносятся отдельной
строкой, потому что именно они рушат доверие к статье.

## Экспорт

По умолчанию — таблица в чат **и** сохранение `.md` в рабочую папку. Имя файла:
`factcheck-<краткая-тема>-<порядковый номер>.md` (без дат в имени, тему бери из статьи).

**Google Sheets** (по запросу «выгрузи в гугл-таблицу»): используй доступный Google Workspace
MCP — создай таблицу, залей строки, при возможности примени условное
форматирование по статусу (зелёный/красный/жёлтый). Верни shareable-ссылку.

**Excel `.xlsx`** (по запросу «выгрузи в эксель»): собери книгу через `openpyxl` (шапка
жирным, автоширина, заливка статуса цветом). Скрипт держи в scratchpad, не хардкодь пути —
бери рабочую директорию из контекста. Верни путь к файлу.

Оба экспорта — поверх уже готовой таблицы; сначала собери и покажи её в чате, экспортируй по
явному запросу.
